ALMA — LES PETITS CHERCHEURS
Version 1

Cette version est une web-app : elle peut être ouverte sur iPhone et ajoutée à l'écran d'accueil.
Les observations sont stockées localement sur l'appareil.

Pour l'installer sur iPhone :
1. Héberger ce dossier sur une adresse HTTPS.
2. Ouvrir l'adresse dans Safari.
3. Partager > Ajouter à l'écran d'accueil.
4. Activer « Ouvrir comme app web » si l'option est proposée.
